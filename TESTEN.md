# Klarscan — so testest du

Danke, dass du dir 8–12 Minuten nimmst. Das ist eine Testversion, kein Store-Produkt.

## Link
https://marco1hh.github.io/klarscan/

1. Am besten Safari (iPhone) oder Chrome (Android).
2. iPhone: Teilen → **Zum Home-Bildschirm**.
3. Android: Menü → **App installieren** / Zum Startbildschirm.

Tester-Code für unbegrenzte PDFs: **KLAR2026**  
Einstellungen → Code eintragen → Freischalten.

## Bitte genau diese 7 Dinge tun
1. Einen **Kassenzettel** fotografieren, Filter **Dokument**, PDF erzeugen, Datei öffnen.
2. Denselben Beleg mit Filter **Original** und **Kräftig** vergleichen.
3. **Zwei Seiten** in ein Dokument.
4. Seite **drehen**, danach **Ränder**.
5. Ein schlechtes Foto (schief, dunkel, Schatten).
6. **QR** oder Barcode auf einer Packung scannen.
7. Unter Einstellungen **Feedback** schreiben: Gerät + was nervte.

Bitte **keine echten Ausweise, Bankkarten oder medizinischen Befunde** nehmen.
